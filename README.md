# Aura Lossless Audio Player (Jukebox)

音質最優先設計のクロスプラットフォーム（macOS / Windows）ロスレス音楽プレイヤーアプリケーションです。  
Sony Music Center for PCのような直感的なアルバム一覧表示（グリッド表示）と、オーディオファン向けのDAC直接出力・ビットパーフェクト再生機能を備えています。

---

## 🌟 一般的なプレイヤーとの決定的な違い（音質優位性）

| 項目 | 一般的なプレイヤー (iTunes / Music.app等) | Aura Lossless Audio Player |
| :--- | :--- | :--- |
| **音声出力経路** | OSの共用ミキサー（DirectSound / CoreAudio標準ミキサー）を経由 | **DAC直接出力 / WASAPI排他モード**によりOSミキサーを完全バイパス |
| **サンプリング周波数** | OS設定（44.1kHzや96kHz等）に強制リサンプリング | **音源本来の周波数（44.1k, 96k, 192k等）にCoreAudio/WASAPIを通じてDACのハードウェアクロック（PLL）が自動追従・完全一致** |
| **音量制御** | デジタル演算によるビット落ち（量子化誤差・ダイナミックレンジ劣化） | **Bit-Perfect 0dB固定（ユニティゲイン）**。DACハードウェア側で音量調整 |
| **ギャップ処理** | 曲ごとにストリームを再構築（無音ギャップ・DAC再認識ラグ発生） | **True ギャップレス再生**（ストリームを切断せずPCMバッファをリアルタイム直接結合） |
| **対応ハイレゾ** | フォーマット制限やダウンサンプリング | **FLAC / WAV / AIFF / ALAC (最大192kHz / 24bit〜32bit)** を完全ロスレス再生 |

## 🎧 主要機能 & 仕様詳細

### 1. 🖼️ アルバムグリッド表示（レスポンシブ自動折り返し & サイズ可変スライダー）
- **動的レスポンシブ折り返し（Auto-Wrapping）**:
  - ウィンドウの幅や高さの変化、サイドバーの開閉、スクロールバーの有無に応じて、ビューポート幅から最適なカラム数（列数）をリアルタイムに自動計算。
  - 横スクロールバーを完全に排除し、画面サイズに合わせてカードが自然に次の行へ折り返されます（狭い画面: 2〜3列、通常: 4〜5列、ワイド/全画面: 6〜8列以上）。
- **ジャケットサイズ調整スライダー（`▫ ──[🔘]── ◻`）**:
  - 画面右上（アルバム件数の右側）のスライダーで、アルバムジャケットの表示サイズを **110px〜260px** までシームレスに変更可能。
  - スライダー操作に連動してジャケット画像とカードサイズがリアルタイムに拡縮され、列数の折り返しも瞬時に自動再計算。
  - 設定したジャケットサイズはSQLiteデータベースに自動保存され、次回起動時にも復元されます。
- **ハイレゾバッジ表示**:
  - ハイレゾ音源を含むアルバムにはゴールドの「**Hi-Res AUDIO**」バッジおよび「**FLAC 96k/24b**」等のフォーマットバッジを自動付与。
- **アルバム単位のワンクリック再生 & 詳細展開**:
  - アルバムカードクリックで曲一覧を展開、ダブルクリックでアルバム全曲を再生キューに追加。

### 2. 🎵 曲一覧ビュー（双方向カラムソート & 再生中「♪」インジケーター）
- **双方向数値ソート**:
  - 各カラムヘッダー（`#`、`タイトル`、`アーティスト`、`アルバム`、`フォーマット`、`時間`）をクリックして昇順・降順にワンクリックソート。
  - `#`（トラック番号）や`時間`（再生時間）は文字列順ではなく**数値・秒数**で正確にソート。
  - ソートした表示順のままダブルクリックで再生キューを再構成。
- **再生中インジケーター**:
  - 現在再生中のトラックのトラック番号欄にゴールドの「**♪**」アイコンを表示し、曲タイトルもゴールド色でハイライト。

### 3. ⚡ ハイレゾ・ビットパーフェクト再生（Bit-Perfect Direct Mode）
- **0dB ユニティゲイン出力**:
  - ソフトウェアによる音量減衰やDSP処理（ミキサー・リサンプラー・ディザリング等）を一切行わず、音源ファイルのPCMビット列をそのままDACへ送信。
  - ビットパーフェクト時はソフトウェア音量スライダーを100%（0dB）にロック。
- **DACハードウェアクロック自動追従**:
  - 音源ファイルのサンプリング周波数（44.1kHz, 88.2kHz, 96kHz, 176.4kHz, 192kHz等）に合わせて、macOS Core Audio / Windows WASAPIを通じてDACのPLLハードウェアクロック周波数を自動切り替え。
- **ワンクリック切替**:
  - 画面下部プレイヤーバーの「**⚡ BIT-PERFECT**」ボタンまたはDAC設定ダイアログからいつでも有効/無効を切り替え可能。

### 4. ⚡ True ギャップレス再生（True Gapless Playback）
- **同一サンプリングレート間の完全シームレス結合**:
  - ライブ盤、クラシック組曲、DJメドレー、繋ぎのあるコンセプトアルバム等で、楽曲間に生じる無音時間（ギャップ）やDACの再初期化ラグ（ポップノイズ）を完全解消。
  - 現在の曲の再生中に次曲のファイルハンドルを先行待機（プリバッファリング）。
  - 曲末尾に達した瞬間、PortAudioの同一オーディオコールバックバッファ内で次曲の冒頭PCMデータを直接結合。音声出力ストリーム（`OutputStream`）を切断・再起動することなく1サンプル単位の精度で隙間なく再生。
- **異なるサンプリングレート時の自動フォールバック**:
  - サンプリングレートが異なる楽曲へ移行する際（例: 44.1kHz ➜ 96kHz）は、DACのハードウェアクロック再同期が必要なため、自動的に通常のDACクロック追従モード（ストリーム再構築）へ安全に移行。
- **1曲リピート（🔂）のギャップレスループ**:
  - 1曲リピート再生時もトラック末尾から先頭へシームレスにループ再生。
- **ON/OFF オプション**:
  - 「DAC & オーディオ設定」ダイアログからいつでもワンクリックで有効/無効を切替可能（デフォルト: 有効、SQLite設定保存）。

### 5. 🎛️ 再生コントロール & プレイヤーバー
- **下部常駐プレイヤーバー**:
  - **左側**: 現在再生中トラックのアルバムアートワーク（54x54px）、曲名、アーティスト名、Hi-Resバッジをコンパクトに常時表示。
  - **中央**: 
    - シャッフルボタン（`🔀` ON/OFF）
    - トランスポートボタン（`⏮` 前の曲、`▶ / ⏸` 再生・一時停止、`⏭` 次の曲）
    - リピートボタン（`🔁` オフ ➜ 全曲リピート `🔁` ➜ 1曲リピート `🔂` の3段階）
    - シークバー & 経過時間/総時間表示
    - DAC出力テレメトリ表示（接続DAC名、再生中サンプルレート・ビット深度）
  - **右側**: DAC選択コンボボックス、DAC詳細設定ボタン（`⚙`）、Bit-Perfectボタンスイッチ、音量スライダー。

### 6. 📦 コンピレーション結合（アルバムアーティストでまとめる）機能
- **サイドバー / DAC設定ダイアログから切替**:
  - **ON（推奨）**: `Album Artist`（例: "Various Artists"、サウンドトラック名義など）が設定されているアルバムは、曲ごとにアーティストが異なっていても1枚のアルバムとしてまとめて表示。
  - **OFF**: 各曲の個別アーティスト名義でアルバムを厳密に分割して別々に表示。
  - 切り替え時は音源の再スキャン不要で、SQLiteデータベースが即座に再構成されます。

### 7. 🗄️ ローカルデータベース（SQLite）による高速ライブラリ管理
- **高速バックグラウンドスキャン**:
  - 音楽フォルダーを指定するだけで、サブフォルダーを含め再帰的に高速スキャン。
  - Mutagenライブラリにより正確なMPEGフレーム長（埋め込みジャケット画像サイズに影響されない真の演奏時間）を算出し、曲末尾の無音やシーク時のフリーズを防止。
  - 埋め込みアートワークを自動抽出してキャッシュ保存。
  - インクリメンタル検索（アルバム名、アーティスト名、曲名）。

## 🛠️ システムアーキテクチャ & 設計仕様

```
aura-player/
├── main.py                     # アプリケーション起動エントリポイント
├── run.sh / run.bat            # 各OS用起動スクリプト
├── app/
│   ├── core/
│   │   ├── audio_engine.py     # PortAudio/sounddeviceによるBit-Perfect再生エンジン
│   │   ├── macos_audio.py      # macOS CoreAudio C-types DACハードウェアクロック制御
│   │   ├── database.py         # SQLiteライブラリ管理・各種設定永続化
│   │   ├── scanner.py          # 高速メタデータ抽出・埋め込みアートワークキャッシュ
│   │   └── models.py           # Track, Album, AudioDevice データクラス
│   ├── ui/
│   │   ├── styles.py           # ダークオーディオファイルテーマ (QSS)
│   │   ├── main_window.py      # メインウィンドウ、ルーティング、再生キュー制御
│   │   ├── album_grid.py       # レスポンシブアルバムグリッド、サイズ可変スライダー
│   │   ├── album_detail.py     # アルバム詳細・トラックリスト表示
│   │   ├── track_table.py      # 全曲一覧表示、数値ソート、♪インジケーター
│   │   ├── player_bar.py       # 下部プレイヤーバー、リアルタイムテレメトリ
│   │   └── dac_dialog.py       # DAC設定、音質設定、フォルダー管理ダイアログ
```

### データベース設定一覧 (`settings` テーブル)

| キー | デフォルト値 | 説明 |
| :--- | :--- | :--- |
| `selected_dac_index` | `None` (システム標準) | 選択中のDAC/出力デバイスのPortAudioインデックス |
| `bit_perfect` | `"1"` (有効) | ビットパーフェクト直接出力モード (0dB固定) |
| `gapless_playback` | `"1"` (有効) | 同一サンプリングレート楽曲間のTrueギャップレス再生 |
| `album_jacket_size` | `"170"` | アルバム一覧画面のジャケット表示サイズ (px) |
| `group_by_album_artist` | `"1"` (有効) | コンピレーション結合（アルバムアーティストでまとめる） |

## 🎵 対応フォーマット & ハイレゾ基準

### 対応オーディオ形式
- **FLAC** (`.flac`) - ロスレス圧縮（推奨）
- **WAV** (`.wav`) - リニアPCM
- **AIFF** (`.aif`, `.aiff`) - AppleリニアPCM
- **ALAC / M4A** (`.m4a`) - Apple Lossless
- **MP3 / AAC / OGG** (`.mp3`, `.aac`, `.ogg`)

### ハイレゾ音源認定基準
以下のいずれかを満たす音源に「**Hi-Res AUDIO**」ゴールドバッジを付与します：
- ビット深度が **24-bit** 以上（24bit, 32bit float）
- サンプリング周波数が **88.2 kHz** 以上（88.2k, 96k, 176.4k, 192k, 384k）

## 🚀 起動方法

### macOS / Linux
ターミナルで以下のコマンドを実行します：
```bash
./run.sh
```
または：
```bash
source .venv/bin/activate
python3 main.py
```

### Windows
`run.bat` をダブルクリックするか、PowerShell / コマンドプロンプトで実行します：
```bat
run.bat
```
または：
```bat
.venv\Scripts\activate
python main.py
```
